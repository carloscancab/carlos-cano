# Carlos Cano

Personal site. Brands, narratives, and content in Web3.

## Stack

TanStack Start, React 19, Vite, Tailwind v4. Deploys to Vercel.

## Local

```bash
npm install
npm run dev
```

## Deploy (GitHub → Vercel)

Push to `main`. Vercel builds with `npm run build` on Node 22. No env vars required.
